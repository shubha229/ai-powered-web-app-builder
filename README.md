# 🚀 AI Powered Web App Builder

An AI-powered web application that transforms natural language prompts into responsive web applications. Users can describe their ideas, and the application generates HTML, CSS, and JavaScript code with a live preview, making web development faster and more accessible.

---

## 📌 Features

- 🤖 Generate web applications from text prompts using AI.
- ⚡ Real-time code generation and live preview.
- 💻 Interactive code editor for modifying generated code.
- 🎨 Modern, responsive, and user-friendly interface.
- 🔄 Regenerate applications with updated prompts.
- 📁 Project workspace for organizing generated apps.
- 🚀 One-click deployment support.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/shubha229/ai-powered-web-app-builder.git
```

### 2. Navigate to the project directory

```bash
cd ai-powered-web-app-builder
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create a `.env` file

```env
VITE_GEMINI_API_KEY=YOUR_API_KEY
```

### 5. Start the development server

```bash
npm run dev
```

## 🚀 Usage

1. Enter your application idea as a prompt.
2. Click **Generate**.
3. AI generates the application code.
4. Preview the generated application instantly.
5. Modify the generated code if required.
6. Deploy or download your application.
